Step 4 — Build a Gymnasium environment (wrap simulator for RL)

Create a gymnasium.Env that at each step exposes a state (ready tasks + node states) and accepts actions (assign task i -> node j). Put in src/envs/sage_env.py.

Skeleton:

import gymnasium as gym
from gymnasium import spaces
import numpy as np

class SageEnv(gym.Env):
    def __init__(self, sim_builder, max_tasks=20, num_nodes=2):
        super().__init__()
        self.sim_builder = sim_builder  # function to produce simulator instance
        # define observation and action spaces (simple fixed-size)
        self.observation_space = spaces.Box(low=0, high=1, shape=(max_tasks+num_nodes,), dtype=np.float32)
        self.action_space = spaces.Discrete(max_tasks * num_nodes)  # map idx -> (task,node)
    def reset(self):
        self.sim = self.sim_builder()
        # build initial obs
        return self._get_obs(), {}
    def step(self, action):
        task_idx = action // self.num_nodes
        node_idx = action % self.num_nodes
        # apply action: scheduler assigns task to node in sim
        reward = -1.0  # placeholder: compute negative objective delta
        done = False
        info = {}
        return self._get_obs(), reward, done, False, info
    def _get_obs(self):
        # TODO: build observation vector
        return np.zeros(self.observation_space.shape, dtype=np.float32)


You’ll refine obs/action shapes as you iterate. The key is to have a working env to plug into SB3.

Step 6 — Digital Twin (DT) predictor

DT maps (task features, node features) → predicted runtime and uncertainty.

Quick skeleton using scikit-learn:

# src/dt/predictor.py
from sklearn.ensemble import GradientBoostingRegressor
import numpy as np
import joblib

class DTPredictor:
    def __init__(self):
        self.model = GradientBoostingRegressor()
    def featurize(self, task, node):
        return np.array([task.work, node.speed, node.power, task.affinity_val])
    def fit(self, X, y):
        self.model.fit(X, y)
    def predict(self, X):
        return self.model.predict(X)


Collect training data from early simulator runs (task.work, node.speed) → observed runtime, then fit. Later replace with a PyTorch MLP that can output quantiles or use QuantileRegressor for uncertainty.

Step 7 — Integrate DT into agent decision loop (look-ahead)

Modify your Gym env or the agent wrapper to:

Ask policy for top-K candidate actions (you can sample actions and score them).

For each candidate, call DT to simulate short-horizon outcomes (runtime, energy).

Use Pareto filtering & scalarization to pick final action.

Execute that action in the simulator.

This makes the agent actor-proposer + DT evaluator.
